# Bass & Lights

A 4-page personal website about music festivals and concert experiences.

## Pages
- `index.html` - Home
- `festivals.html` - Festivals (EDC, CRSSD, HARD Summer, Nocturnal Wonderland)
- `artists.html` - Artists & Genres
- `guide.html` - Festival Survival Guide

## Structure
- `css/styles.css` - main external stylesheet
- `images/` - site images
